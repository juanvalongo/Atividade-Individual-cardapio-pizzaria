# Atividade-Individual-cardapio-pizzaria
Aplicação web responsiva e interativa desenvolvida para a disciplina de Coding: Mobile do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas (ADS) do SENAC Recife (3º Período).<br>

Link do projeto no [GitHub Pages](https://juanvalongo.github.io/Atividade-Individual-cardapio-pizzaria/).

## 📌 Sobre o Projeto
O projeto consiste em um cardápio digital para uma pizzaria, construído progressivamente ao longo do semestre para aplicar conceitos de desenvolvimento web focado em dispositivos móveis.

## 📋 Atividades Desenvolvidas:

### Atividade Individual 1: Web Responsivo
Desenvolva individualmente um projeto web responsivo, utilizando **HTML, CSS e JavaScript**, com temática livre. O projeto deve apresentar uma interface organizada, adaptar-se adequadamente a diferentes tamanhos de tela e utilizar JavaScript para implementar algum tipo de interação ou comportamento dinâmico.

A entrega deverá conter:
- Link do **repositório público no GitHub**, contendo todo o código-fonte do projeto;
- Link da **aplicação publicada e acessível online**, utilizando GitHub Pages, Netlify, Vercel ou outra plataforma semelhante.

O projeto será avaliado considerando a organização do código, uso adequado de HTML, CSS e JavaScript, responsividade, funcionamento da aplicação e qualidade geral da solução desenvolvida.

### Atividade Individual 2: Aplicação Web Responsiva com Consumo de API
Desenvolva uma aplicação web responsiva, com temática livre, aplicando boas práticas de design e usabilidade para dispositivos móveis. O projeto deverá adaptar-se adequadamente a diferentes tamanhos de tela, apresentar uma interface organizada e obter bons resultados de desempenho, acessibilidade e boas práticas na avaliação do **Google Lighthouse**.

A aplicação deverá consumir dados de pelo menos uma **API externa**, utilizando JavaScript para realizar as requisições e apresentar as informações de forma dinâmica em uma ou mais telas da aplicação.

**Entregáveis:**
- Link do **repositório público no GitHub**, contendo todo o código-fonte do projeto.
- Link da **aplicação publicada**, utilizando GitHub Pages, Vercel, Netlify ou outra plataforma de deploy.

### Atividade Individual 3: Desenvolver um PWA com Recursos de Hardware
Utilize como base o projeto web que vem sendo desenvolvido ao longo da disciplina ou crie uma nova aplicação e adapte-a para funcionar como uma **Progressive Web App (PWA)**.

A aplicação deverá:

- Ser instalável como PWA;
- Possuir funcionamento adequado em dispositivos móveis;
- Utilizar pelo menos **um recurso de hardware ou funcionalidade do dispositivo**, como câmera, GPS/geolocalização, microfone, entre outros;
- Apresentar uma interface responsiva e funcional.

**Entregáveis:**
- Link do **repositório público no GitHub;**
- Link da **aplicação publicada** (GitHub Pages, Vercel, Netlify ou plataforma equivalente).
